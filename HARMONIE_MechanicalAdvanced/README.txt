HARMONIE - Mechanical Advanced [B42]
====================================
ม็อดปรับแต่ง/อัพเกรดรถให้เก่งขึ้น -- ใช้ API ของเกม Build 42 ล้วนๆ ไม่พึ่งม็อดของคนอื่นเลย


ม็อดนี้ทำอะไรได้บ้าง
====================

เพิ่มอุปกรณ์เสริมสำหรับรถยนต์ของแท้ในเกม **152 รุ่น** (แทบทุกรถที่ขับได้จริงในเกม รวมรถลาย/รุ่น
เฉพาะอาชีพเกือบทั้งหมด) 5 ชิ้น (ครอบคลุม 3 ชิ้นส่วนติดตั้งจริง เพราะเกราะกันกระจกแยกเป็น
บานหน้า+ประตูซ้าย+ประตูขวา) -- ดูรายชื่อรถที่รองรับด้านล่าง:

1. บูลบาร์ (Bullbar)
   - กันชนหน้าเสริมความแข็งแรง **ตอบสนองต่อการชนจริง** (ชนซอมบี้/สิ่งของ) โดยเช็คค่า
     frontEndHealth ของรถจริงทุกรอบ ถ้าลดลง (แปลว่ามีการชนจริงเกิดขึ้น) สภาพของบูลบาร์เองจะสึกลง
     ตามไปด้วย -- **ไม่ได้ลดความเสียหายที่ตัวรถได้รับจริงๆ** (หาวิธี "ป้องกัน" ที่ยืนยันได้จริงไม่เจอ
     ในโค้ดเกม เลยเลือกทำแค่ส่วนที่ยืนยันได้แน่ชัด คือให้กันชนสึกจริงตามการชนจริง แทนที่จะค้าง 100%
     ตลอดแบบเดิม)
   - คราฟต์เอง แล้วติดตั้งที่เครื่องยนต์
   - ติดตั้ง: ประแจ (Wrench) + ทักษะ Mechanics ระดับ 5 ขึ้นไป (งานยึด/ประกอบเชิงกล)

2. เกราะกันกระจกหน้า (Windshield Armor)
3. เกราะกันกระจกข้างคนขับ ซ้าย/ขวา (Door Window Armor)
   - แผ่นเหล็กเชื่อมเสริมความแข็งแรง ไอเทมเดียวกันใช้ติดได้ทั้ง 3 จุด (หน้า/ซ้าย/ขวา) -- ตอนนี้เป็น
     อุปกรณ์เสริมความทนทานเฉยๆ (สึกหรอช้ากว่าอุปกรณ์ทั่วไปตามค่า durability) ยังไม่มีกลไกป้องกันกระจก
     จริงจากการแตกโดยตรง (ตัดสินใจไม่ใส่เพราะไม่สามารถยืนยัน part id จริงของกระจก/ประตูแต่ละรุ่นรถ
     ได้อย่างปลอดภัย จะได้ไม่เขียนโค้ดที่อ้างอิงชื่อชิ้นส่วนแบบเดามั่ว)
   - คราฟต์เอง แล้วติดตั้งที่กระจกแต่ละจุด
   - ติดตั้ง: ประแจ + ทักษะ Metal Welding ระดับ 3 ขึ้นไป (งานเชื่อม)

4. แร็คสัมภาระท้ายรถ (Cargo Rack)
   - โครงเหล็กติดตั้งที่กระบะท้าย เปิดเป็น**ช่องเก็บของแยกต่างหากจริง** ความจุ 30 หน่วย (คนละช่องกับ
     ที่เก็บของเดิมของรถ) เข้าถึงได้เหมือนกระโปรงท้ายรถทั่วไป
   - คราฟต์เอง แล้วติดตั้งที่กระบะท้าย
   - ติดตั้ง: ประแจ + ทักษะ Metal Welding ระดับ 3 ขึ้นไป (งานเชื่อม)

5. ชุดท่อไอเสียปรับแต่งสมรรถนะ (Performance Exhaust Kit)
   - อัพเกรด "ของจริง" ไม่ใช่แค่ของตกแต่ง: เพิ่มแรงม้าเครื่องยนต์จริงในเกม (~+15% ตอนสภาพอุปกรณ์เต็ม
     ร้อย ยิ่งอุปกรณ์สึกยิ่งได้โบนัสน้อยลง)
   - คราฟต์เอง แล้วติดตั้งที่เครื่องยนต์
   - ติดตั้ง: ประแจ + ทักษะ Mechanics ระดับ 5 **และ** Metal Welding ระดับ 3 ขึ้นไปทั้งคู่
     (งานทั้งเชิงกลและเชื่อม จึงต้องมีทั้งสองทักษะ -- ของ "ขั้นสูง" ตามชื่อม็อด)
   - มีบทพูดพิเศษตอนติดตั้งถ้าตัวละครมีทักษะ Mechanics สูงพอ ต่างจากบทพูดทั่วไป

หมายเหตุเรื่องทักษะ: ค่า "ทักษะ" ที่ระบุ**ไม่ได้บล็อกการติดตั้งเด็ดขาด** -- ตามกลไกจริงของเกม (เช็ค
จากโค้ด ISInstallVehiclePart.lua) ทักษะจะถูกใช้คำนวณ "% โอกาสสำเร็จ" ของการติดตั้งแต่ละครั้งแทน
ทักษะสูงกว่าเกณฑ์ = โอกาสสำเร็จสูงขึ้น ทักษะต่ำกว่า = เสี่ยงติดตั้งไม่สำเร็จ (แต่ยังลองได้เสมอ)



ต้องมีอะไรบ้างก่อนใช้งาน
========================

- แค่ Build 42 (versionMin=42.0.0) เท่านั้น -- **ไม่ต้องพึ่งม็อดตัวอื่นเลย** ทุกอย่างเขียนด้วย API
  ของเกมล้วนๆ (vehicle:setEngineFeature, Vehicles.InstallTest.Default ฯลฯ ที่มากับตัวเกมเอง)


วิธีติดตั้ง/เปิดใช้งาน
======================

1. เปิดใช้ "HARMONIE - Mechanical Advanced" ในเมนู Mods ของเกม (ม็อดเดียว ไม่ต้องเปิดอย่างอื่นเพิ่ม)
2. เข้าเกม/โหลดเซฟ
3. หารถ (ดูรายชื่อรุ่นที่รองรับด้านล่าง) ในโลกเกม -- **สำคัญ: ต้องเป็นคันที่ยังไม่เคยถูกโหลด/มองเห็น
   มาก่อนในเซฟนี้** (เช่น เริ่มเกมใหม่ หรือไปพื้นที่ที่ยังไม่เคยไป) เพราะชิ้นส่วนของรถแต่ละคันจะถูก
   "ล็อก" ไว้ตั้งแต่ตอนที่รถถูกสร้าง/โหลดเข้าเกมครั้งแรก รถที่เคยเห็นมาก่อนตั้งแต่ยังไม่ได้เปิดม็อดนี้
   จะไม่ได้รับชิ้นส่วนใหม่ย้อนหลัง (ข้อจำกัดปกติของม็อดแนวเพิ่มชิ้นส่วนรถทุกตัวใน PZ)
4. คราฟต์ไอเทมที่ต้องการ (ดูสูตรด้านล่าง) แล้วเข้าเมนูซ่อม/mechanic ของรถ (คลิกขวาที่รถ หรือเข้าโหมด
   Mechanic) เลือกติดตั้งอุปกรณ์ที่คราฟต์ไว้


สูตรคราฟต์
==========

บูลบาร์:
  - บล็อกโทรช (Base.BlowTorch) x2, หน้ากากเชื่อม (ถือ/ใส่ไว้ ไม่เสียของ)
  - ท่อโลหะ (Base.MetalPipe) x3, เหล็กแท่ง (Base.MetalBar) x1
  - ทักษะ Metal Welding 3+

แผ่นเกราะกันกระจก (ใช้ได้ทั้งกระจกหน้า/ข้าง):
  - บล็อกโทรช x2, หน้ากากเชื่อม
  - แผ่นเหล็กชิ้นเล็ก (Base.SmallSheetMetal) x2
  - ท่อโลหะ x1
  - ทักษะ Metal Welding 3+

โครงแร็คสัมภาระท้ายรถ:
  - บล็อกโทรช x2, หน้ากากเชื่อม
  - เหล็กแท่ง x2, ท่อโลหะ x2
  - ทักษะ Metal Welding 3+

ชุดท่อไอเสียปรับแต่งสมรรถนะ:
  - บล็อกโทรช x2, หน้ากากเชื่อม
  - ท่อโลหะ x2, น็อตสกรู (Base.Screws) x4
  - ทักษะ Mechanics 5+ และ Metal Welding 3+

(สูตรคราฟต์ทั้งหมดใช้ blowtorch เผาเชื่อมที่โต๊ะ/พื้นที่งานฝีมือ ไม่ต้องมีเตาเผา -- ส่วนตอน "ติดตั้ง"
ลงรถจริงๆใช้แค่ประแจตามที่ระบุไว้ในหัวข้อด้านบน แต่ทักษะที่ต้องใช้ตอนติดตั้งอาจสูงกว่าตอนคราฟต์
เพราะ "ประกอบเข้ากับรถจริง" ต้องการความชำนาญมากกว่า "ทำชิ้นส่วนเปล่าๆ" -- ดูตัวเลขติดตั้งจริงในหัวข้อ
"ม็อดนี้ทำอะไรได้บ้าง" ด้านบน)



ภาษาที่รองรับ
==============
อังกฤษ (EN) และไทย (TH) เต็มรูปแบบ -- ชื่อไอเทม, ชื่อสูตรคราฟต์, บทพูดตอนติดตั้ง/ถอดอุปกรณ์


รองรับ Multiplayer
===================
รองรับ -- ข้อมูล "ใครติดตั้งอุปกรณ์ชิ้นนี้ วันที่เท่าไหร่" จะ sync ให้ผู้เล่นทุกคนเห็นตรงกันผ่าน
ระบบ ModData มาตรฐานของเกม (part:getModData() + vehicle:transmitPartModData())


สถานะปัจจุบัน / ข้อจำกัดที่รู้อยู่แล้ว
======================================

- เดิมม็อดนี้พึ่งพาม็อดเสริม "tsarslib" (Tsar's Common Library) ในการจัดการระบบอัพเกรดรถ แต่ภายหลัง
  พบว่า Workshop item ของ tsarslib ที่ใช้อยู่ (id 3402491515) ถูก Steam ถอดออกเพราะผิดกฎ Content
  Guidelines (เป็นการเอาม็อดของคนอื่นมาอัปโหลดแทนโดยไม่ได้รับอนุญาต) -- จึงเขียนม็อดใหม่ทั้งหมดให้
  ใช้ API ของเกมล้วนๆ ไม่พึ่งม็อดใครอีกต่อไป ปลอดภัยกว่าเดิมในระยะยาว

- ม็อดนี้สร้างขึ้นหลังศึกษาม็อด "Standardized Vehicle Upgrades 3 - Core" ที่ใช้งานไม่ได้จริง
  (นิยามข้อมูลไว้เฉยๆ แต่ไม่เคยเรียกฟังก์ชันลงทะเบียนจริงกับรถคันไหนเลย) -- ม็อดนี้แก้ปัญหานั้นโดย
  ลงทะเบียนชิ้นส่วนกับรถกระบะจริงตั้งแต่แรก ผ่าน getScriptManager():getVehicle():Load() ซึ่งเป็น
  ฟังก์ชันของเกมเองโดยตรง

- อัปเดตจากการทดสอบในเกมจริงจริง (แก้แล้ว): เจอ 3 บั๊กจากการเทสจริง --
  (1) ติดตั้งของทุกคันแรกที่โหลดพังเพราะพยายามยัดของให้ทุกชิ้นส่วนอัตโนมัติตอนรถถูกสร้าง (แก้แล้ว),
  (2) บทพูดไม่เคยขึ้นเพราะ require path ผิด (แก้แล้ว),
  (3) ชื่อชิ้นส่วนในเมนู mechanic ขึ้นเป็นชื่อโค้ดดิบ เพราะไม่เคยใส่คำแปล IGUI_VehiclePart<ชื่อ>
  ไว้เลย (แก้แล้ว, เพิ่มคำแปล TH/EN ครบทั้ง 6 ชิ้นส่วน),
  (4) error ตอนติดตั้งเสร็จเพราะเรียก API ผิด (calendar:getDayOfMonth() ไม่มีจริง แก้เป็น
  getGameTime():getDay() แล้ว),
  (5) error ทุกครั้งที่ update hook ทำงาน เพราะ part:getConditionMax() ไม่มีจริงเช่นกัน (ใช้ได้แค่กับ
  ไอเทม ไม่ใช่ part ของรถ -- vanilla เองใช้เลข 100 ตรงๆเสมอ แก้ตามนั้นแล้วทั้ง Bullbar และ PerfExhaust),
  (6) บูลบาร์ค้าง 100% ตลอดแม้ชนซอมบี้/สิ่งของ เพราะกลไกเดิมเช็คสภาพของ part "Engine" ซึ่งไม่ได้
  เชื่อมกับการชนจริงเลย (แกะไฟล์ .class ของเกมจริงยืนยันว่าการชนจริงกระทบค่า frontEndHealth/
  rearEndHealth ระดับตัวรถ ไม่ใช่สภาพของ part ใดๆ และไม่มีการเชื่อม Lua ให้ดักจับเหตุการณ์การชนได้เลย)
  แก้เป็นเช็ค vehicle:getFrontEndHealth() ทุกรอบแทน (ยืนยันว่ามีเมธอดนี้จริงจากไฟล์ .class) ถ้าค่าลดลง
  แปลว่าชนจริง จะให้กันชนสึกตาม -- แต่ไม่พบเมธอดสำหรับ "คืนค่า/ป้องกัน" frontEndHealth เลย จึงบอกตรงๆ
  ว่ากันชนตอนนี้แค่ "สึกจริงตามการชนจริง" ไม่ได้ "ลดความเสียหายที่รถได้รับจริง"

- วิธีตรวจสอบเองว่าฟังก์ชันจริงทำงานอยู่หรือไม่ (ตามที่ขอ): เปิด console.txt (อยู่ที่โฟลเดอร์ Zomboid
  ของเกม) แล้วค้นหาคำว่า "HARMONIE Mechanical Advanced:" -- ทุก update hook จะพิมพ์ข้อความยืนยันว่า
  "hook is running" ครั้งแรกที่ทำงานหลังติดตั้ง (เก็บสถานะไว้ใน ModData ของ part เอง ไม่หายแม้เซฟ/โหลด
  ใหม่) และ PerfExhaust จะพิมพ์ค่าแรงม้าที่ตั้งจริงทุกครั้งที่ค่าเปลี่ยน ส่วน Bullbar จะพิมพ์ทุกครั้งที่
  ดูดซับความสึกหรอจริง (เกิดไม่บ่อย เพราะเป็นโอกาสสุ่ม 2% ต่อรอบเช็ค ต้องขับรถให้เครื่องยนต์เสียหาย
  ก่อนถึงจะมีอะไรให้ดูดซับ) -- ถ้าเปิด console.txt แล้วไม่เจอข้อความเหล่านี้เลยหลังผ่านไปสักพัก
  แปลว่า update hook ไม่ทำงานจริง ต้องแจ้งกลับมาเพื่อตรวจสอบเพิ่ม

- แก้ tooltip ก่อนติดตั้งแล้ว (ตามที่ขอ): เดิมหน้าต่าง mechanic ตอน hover เมนู "Install" จะโชว์แค่
  เครื่องมือ/ทักษะที่ต้องใช้ ไม่เคยโชว์ "ชิ้นส่วนนี้ทำอะไรได้" เลย (เช็คโค้ดเกมจริงยืนยันแล้วว่า
  ฟังก์ชันสร้าง tooltip ของเกมไม่เคยดึงคำอธิบายจากไอเทมมาใส่) เพิ่ม hook ให้ดึงคำอธิบายจริงของแต่ละ
  ชิ้นส่วน (Tooltip_HARMONIE_MA_* เดียวกับที่โชว์ตอนดูไอเทมในกระเป๋า) มาต่อท้ายให้แล้ว

- ปรับทักษะขั้นต่ำใหม่ (ตามที่ขอ): แยกตามประเภทงาน -- งานเชิงกล (บูลบาร์) ต้องการ Mechanics 5,
  งานเชื่อม (เกราะกระจก, แร็คสัมภาระ) ต้องการ Metal Welding 3, งานที่ผสมทั้งสองอย่าง (ท่อไอเสีย
  ปรับแต่ง) ต้องการทั้งคู่ -- ทั้งตอนคราฟต์และตอนติดตั้ง

- รูปไอคอนของม็อด (icon.png/poster.png) เป็นภาพชั่วคราว ยังไม่ใช่งานศิลป์จริงของม็อด

- โมเดล 3D และเท็กซ์เจอร์ของไอเทมใหม่ 4 ชิ้น (บูลบาร์, แผ่นเกราะ, แร็ค, ท่อไอเสีย) ยืมมาจาก
  tsarslib (asset ทั่วไปที่ไม่ได้ผูกกับม็อดหรือรถคันไหนเป็นการเฉพาะ -- ไฟล์ asset เองไม่มีปัญหาเรื่อง
  การถูกถอดออกจาก Workshop เพราะ copy เก็บไว้ในเครื่องแล้ว ปัญหามีแค่เรื่อง "โค้ด/ฟังก์ชัน" ที่ต้อง
  พึ่งม็อดคนอื่นตอนรันเท่านั้น ซึ่งตอนนี้ตัดออกหมดแล้ว) ยังไม่ได้เช็คด้วยตาว่า UV/สัดส่วนแสดงผล
  ถูกต้องสวยงามในเกมจริง
