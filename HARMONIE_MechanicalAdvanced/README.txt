HARMONIE - Mechanical Advanced [B42]
====================================
ม็อดปรับแต่ง/อัพเกรดรถให้เก่งขึ้น -- ใช้ API ของเกม Build 42 ล้วนๆ ไม่พึ่งม็อดของคนอื่นเลย


ม็อดนี้ทำอะไรได้บ้าง
====================

เพิ่มอุปกรณ์เสริมสำหรับรถกระบะ (Pick-up Truck) และรถตู้ (Van) ของแท้ในเกม 5 ชิ้น (ครอบคลุม 3 ชิ้นส่วนติดตั้งจริง
เพราะเกราะกันกระจกแยกเป็นบานหน้า+ประตูซ้าย+ประตูขวา):

1. บูลบาร์ (Bullbar)
   - กันชนหน้าเสริมความแข็งแรง กันความเสียหายตอนชนซอมบี้/สิ่งกีดขวาง
   - คราฟต์เอง แล้วติดตั้งที่เครื่องยนต์
   - ติดตั้ง: ประแจ (Wrench) + ทักษะ Mechanics ระดับ 2 ขึ้นไป

2. เกราะกันกระจกหน้า (Windshield Armor)
3. เกราะกันกระจกข้างคนขับ ซ้าย/ขวา (Door Window Armor)
   - แผ่นเหล็กเชื่อมปิดกระจก ไอเทมเดียวกันใช้ติดได้ทั้ง 3 จุด (หน้า/ซ้าย/ขวา)
   - คราฟต์เอง แล้วติดตั้งที่กระจกแต่ละจุด
   - ติดตั้ง: ประแจ + ทักษะ Metal Welding ระดับ 2 ขึ้นไป

4. แร็คสัมภาระท้ายรถ (Cargo Rack)
   - โครงเหล็กเสริมพื้นที่เก็บของบนกระบะท้าย
   - คราฟต์เอง แล้วติดตั้งที่กระบะท้าย
   - ติดตั้ง: ประแจ + ทักษะ Metal Welding ระดับ 3 ขึ้นไป

5. ชุดท่อไอเสียปรับแต่งสมรรถนะ (Performance Exhaust Kit)
   - อัพเกรด "ของจริง" ไม่ใช่แค่ของตกแต่ง: เพิ่มแรงม้าเครื่องยนต์จริงในเกม (~+15% ตอนสภาพอุปกรณ์เต็ม
     ร้อย ยิ่งอุปกรณ์สึกยิ่งได้โบนัสน้อยลง)
   - คราฟต์เอง แล้วติดตั้งที่เครื่องยนต์
   - ติดตั้ง: ประแจ + ทักษะ Mechanics ระดับ 4 ขึ้นไป (ของ "ขั้นสูง" ตามชื่อม็อด)
   - มีบทพูดพิเศษตอนติดตั้งถ้าตัวละครมีทักษะ Mechanics สูงพอ ต่างจากบทพูดทั่วไป


ต้องมีอะไรบ้างก่อนใช้งาน
========================

- แค่ Build 42 (versionMin=42.0.0) เท่านั้น -- **ไม่ต้องพึ่งม็อดตัวอื่นเลย** ทุกอย่างเขียนด้วย API
  ของเกมล้วนๆ (vehicle:setEngineFeature, Vehicles.InstallTest.Default ฯลฯ ที่มากับตัวเกมเอง)


วิธีติดตั้ง/เปิดใช้งาน
======================

1. เปิดใช้ "HARMONIE - Mechanical Advanced" ในเมนู Mods ของเกม (ม็อดเดียว ไม่ต้องเปิดอย่างอื่นเพิ่ม)
2. เข้าเกม/โหลดเซฟ
3. หารถกระบะ (Pick-up Truck) หรือรถตู้ (Van) ในโลกเกม -- **สำคัญ: ต้องเป็นคันที่ยังไม่เคยถูกโหลด/มองเห็น
   มาก่อนในเซฟนี้** (เช่น เริ่มเกมใหม่ หรือไปพื้นที่ที่ยังไม่เคยไป) เพราะชิ้นส่วนของรถแต่ละคันจะถูก
   "ล็อก" ไว้ตั้งแต่ตอนที่รถถูกสร้าง/โหลดเข้าเกมครั้งแรก รถที่เคยเห็นมาก่อนตั้งแต่ยังไม่ได้เปิดม็อดนี้
   จะไม่ได้รับชิ้นส่วนใหม่ย้อนหลัง (ข้อจำกัดปกติของม็อดแนวเพิ่มชิ้นส่วนรถทุกตัวใน PZ)
4. คราฟต์ไอเทมที่ต้องการ (ดูสูตรด้านล่าง) แล้วเข้าเมนูซ่อม/mechanic ของรถ (คลิกขวาที่รถ หรือเข้าโหมด
   Mechanic) เลือกติดตั้งอุปกรณ์ที่คราฟต์ไว้


สูตรคราฟต์
==========

บูลบาร์:
  - บล็อกโทรช (Base.BlowTorch) x2, หน้ากากเชื่อม (ถือ/ใส่ไว้ ไม่เสียของ)
  - ท่อโลหะ (Base.MetalPipe) x3, เหล็กแท่ง (Base.MetalBar) x1
  - ทักษะ Metal Welding 2+

แผ่นเกราะกันกระจก (ใช้ได้ทั้งกระจกหน้า/ข้าง):
  - บล็อกโทรช x2, หน้ากากเชื่อม
  - แผ่นเหล็กชิ้นเล็ก (Base.SmallSheetMetal) x2
  - ท่อโลหะ x1
  - ทักษะ Metal Welding 2+

โครงแร็คสัมภาระท้ายรถ:
  - บล็อกโทรช x2, หน้ากากเชื่อม
  - เหล็กแท่ง x2, ท่อโลหะ x2
  - ทักษะ Metal Welding 3+

ชุดท่อไอเสียปรับแต่งสมรรถนะ:
  - บล็อกโทรช x2, หน้ากากเชื่อม
  - ท่อโลหะ x2, น็อตสกรู (Base.Screws) x4
  - ทักษะ Mechanics 4+ และ Metal Welding 3+

(สูตรทั้งหมดใช้ blowtorch เผาเชื่อมที่โต๊ะ/พื้นที่งานฝีมือ ไม่ต้องมีเตาเผา -- ส่วนตอน "ติดตั้ง" ลงรถ
จริงๆใช้แค่ประแจตามที่ระบุไว้ในหัวข้อด้านบน)


ภาษาที่รองรับ
==============
อังกฤษ (EN) และไทย (TH) เต็มรูปแบบ -- ชื่อไอเทม, ชื่อสูตรคราฟต์, บทพูดตอนติดตั้ง/ถอดอุปกรณ์


รองรับ Multiplayer
===================
รองรับ -- ข้อมูล "ใครติดตั้งอุปกรณ์ชิ้นนี้ วันที่เท่าไหร่" จะ sync ให้ผู้เล่นทุกคนเห็นตรงกันผ่าน
ระบบ ModData มาตรฐานของเกม (part:getModData() + vehicle:transmitPartModData())


สถานะปัจจุบัน / ข้อจำกัดที่รู้อยู่แล้ว
======================================

- เดิมม็อดนี้พึ่งพาม็อดเสริม "tsarslib" (Tsar's Common Library) ในการจัดการระบบอัพเกรดรถ แต่ภายหลัง
  พบว่า Workshop item ของ tsarslib ที่ใช้อยู่ (id 3402491515) ถูก Steam ถอดออกเพราะผิดกฎ Content
  Guidelines (เป็นการเอาม็อดของคนอื่นมาอัปโหลดแทนโดยไม่ได้รับอนุญาต) -- จึงเขียนม็อดใหม่ทั้งหมดให้
  ใช้ API ของเกมล้วนๆ ไม่พึ่งม็อดใครอีกต่อไป ปลอดภัยกว่าเดิมในระยะยาว

- ม็อดนี้สร้างขึ้นหลังศึกษาม็อด "Standardized Vehicle Upgrades 3 - Core" ที่ใช้งานไม่ได้จริง
  (นิยามข้อมูลไว้เฉยๆ แต่ไม่เคยเรียกฟังก์ชันลงทะเบียนจริงกับรถคันไหนเลย) -- ม็อดนี้แก้ปัญหานั้นโดย
  ลงทะเบียนชิ้นส่วนกับรถกระบะจริงตั้งแต่แรก ผ่าน getScriptManager():getVehicle():Load() ซึ่งเป็น
  ฟังก์ชันของเกมเองโดยตรง

- จุดที่ยังไม่ผ่านการทดสอบในเกมจริง: ยังไม่เคยเปิดเกมทดสอบว่าอุปกรณ์ทั้ง 5 ชิ้นขึ้นในเมนู mechanic
  ถูกต้อง แม้จะเขียนตามสูตรของชิ้นส่วนรถจริงในเกม (เช่น Seat*, GasTank, Radio ของ vanilla เอง)
  อย่างละเอียดแล้วก็ตาม

- รูปไอคอนของม็อด (icon.png/poster.png) เป็นภาพชั่วคราว ยังไม่ใช่งานศิลป์จริงของม็อด

- โมเดล 3D และเท็กซ์เจอร์ของไอเทมใหม่ 4 ชิ้น (บูลบาร์, แผ่นเกราะ, แร็ค, ท่อไอเสีย) ยืมมาจาก
  tsarslib (asset ทั่วไปที่ไม่ได้ผูกกับม็อดหรือรถคันไหนเป็นการเฉพาะ -- ไฟล์ asset เองไม่มีปัญหาเรื่อง
  การถูกถอดออกจาก Workshop เพราะ copy เก็บไว้ในเครื่องแล้ว ปัญหามีแค่เรื่อง "โค้ด/ฟังก์ชัน" ที่ต้อง
  พึ่งม็อดคนอื่นตอนรันเท่านั้น ซึ่งตอนนี้ตัดออกหมดแล้ว) ยังไม่ได้เช็คด้วยตาว่า UV/สัดส่วนแสดงผล
  ถูกต้องสวยงามในเกมจริง

- รองรับรถกระบะ (Pick-up Truck) และรถตู้ (Van) ในตอนนี้ (ยืนยันแล้วว่าทั้งคู่มีจุดติดตั้งครบตามที่
  ชิ้นส่วนของเราต้องการ: Engine, TruckBed, GasTank, ที่นั่งหน้าซ้าย/ขวา) รถชนิดอื่น (SUV, OffRoad,
  รถเก๋งทั่วไป, PickupVan, StepVan) ยังไม่เพิ่มให้ เพราะสคริปต์ของรถเหล่านั้นไม่ได้ประกาศพื้นที่
  Engine/TruckBed ไว้ตรงๆในไฟล์ของตัวเอง (อาจจะสืบทอดมาจากที่อื่นก็ได้ แต่ยังไม่ได้ตรวจสอบให้แน่ใจ)
  ต้องตรวจสอบให้ชัดเจนก่อนเพิ่ม ไม่อยากเดาแล้วพัง -- ถ้าต้องการให้เพิ่มรถคันไหน แจ้งได้เลย
  (แค่เรียก registerUpgrades("ชื่อรถ") เพิ่มใน HARMONIE_MA_TuningTable.lua หลังยืนยัน area แล้ว)
