HARMONIE - Mechanical Advanced [B42]
====================================
ม็อดปรับแต่ง/อัพเกรดรถให้เก่งขึ้น สร้างบนระบบ Tuning2 ของ tsarslib (Tsar's Common Library)


ม็อดนี้ทำอะไรได้บ้าง
====================

เพิ่มอุปกรณ์เสริมสำหรับรถกระบะ (Pick-up Truck) ของแท้ในเกม 5 ชิ้น:

1. บูลบาร์ (Bullbar)
   - กันชนหน้าเสริมความแข็งแรง กันความเสียหายตอนชนซอมบี้/สิ่งกีดขวาง
   - ใช้ไอเทมของ tsarslib เองเลย (ไม่ต้องคราฟต์ใหม่ หาได้ตามจุดสปอว์นทั่วไป)
   - ติดตั้ง: ต้องมีประแจ (Wrench) + ทักษะ Mechanics ระดับ 2 ขึ้นไป

2. เกราะกันกระจกหน้า (Windshield Armor)
3. เกราะกันกระจกข้างคนขับ ซ้าย/ขวา (Door Window Armor)
   - แผ่นเหล็กเชื่อมปิดกระจก กันกระจกแตกจากการชน/ซอมบี้ตี
   - คราฟต์ไอเทม "แผ่นเกราะกันกระจก" เองได้ (ดูสูตรด้านล่าง) แล้วเอาไปติดตั้งกับรถ
   - ติดตั้ง: ต้องใส่หน้ากากเชื่อม (Welding Mask) + ทักษะ Metal Welding ระดับ 2 ขึ้นไป

4. แร็คสัมภาระท้ายรถ (Cargo Rack)
   - โครงเหล็กเสริมพื้นที่เก็บของบนกระบะท้าย
   - คราฟต์ไอเทม "โครงแร็คสัมภาระท้ายรถ" เองได้ แล้วติดตั้งที่กระบะท้าย
   - ติดตั้ง: ต้องใส่หน้ากากเชื่อม + ทักษะ Metal Welding ระดับ 3 ขึ้นไป

5. ชุดท่อไอเสียปรับแต่งสมรรถนะ (Performance Exhaust Kit)
   - อัพเกรด "ของจริง" ไม่ใช่แค่ของตกแต่ง: เพิ่มแรงม้าเครื่องยนต์จริงในเกม (~+15% ตอนสภาพอุปกรณ์เต็ม
     ร้อย ยิ่งอุปกรณ์สึกยิ่งได้โบนัสน้อยลง)
   - คราฟต์ไอเทม "ชุดท่อไอเสียปรับแต่งสมรรถนะ" เองได้ แล้วติดตั้งที่เครื่องยนต์
   - ติดตั้ง: ต้องมีประแจ + ทักษะ Mechanics ระดับ 4 ขึ้นไป (ของ "ขั้นสูง" ตามชื่อม็อด)
   - มีบทพูดพิเศษตอนติดตั้งถ้าตัวละครมีทักษะ Mechanics สูงพอ ต่างจากบทพูดทั่วไป


ต้องมีอะไรบ้างก่อนใช้งาน
========================

- เปิดใช้ม็อด "tsarslib" (Tsar's Common Library) ก่อนเสมอ -- ม็อดนี้อาศัยระบบ Tuning2 ของ tsarslib
  ทั้งหมด ถ้าไม่มี tsarslib จะขึ้น error ทันทีตอนโหลดเกม (ข้อความจะบอกชัดเจนว่าเพราะอะไร)
- Build 42 (versionMin=42.0.0 เท่านั้น ยังไม่รองรับ B41)


วิธีติดตั้ง/เปิดใช้งาน
======================

1. เปิดใช้ทั้ง "tsarslib" และ "HARMONIE - Mechanical Advanced" ในเมนู Mods ของเกม
2. เข้าเกม/โหลดเซฟ
3. หารถกระบะ (Pick-up Truck) ในโลกเกม
4. คราฟต์ไอเทมที่ต้องการ (ดูสูตรด้านล่าง) แล้วเข้าเมนูซ่อม/tuning ของรถ (คลิกขวาที่รถ หรือเข้าโหมด
   Mechanic) เลือกติดตั้งอุปกรณ์ที่คราฟต์ไว้


สูตรคราฟต์
==========

แผ่นเกราะกันกระจก (ใช้ได้ทั้งกระจกหน้า/ข้าง):
  - บล็อกโทรช (Base.BlowTorch) x2 (ใช้เป็นเชื้อเพลิงเชื่อม)
  - หน้ากากเชื่อม (ถือ/ใส่ไว้ ไม่เสียของ)
  - แผ่นเหล็กชิ้นเล็ก (Base.SmallSheetMetal) x2
  - ท่อโลหะ (Base.MetalPipe) x1
  - ทักษะ Metal Welding 2+

โครงแร็คสัมภาระท้ายรถ:
  - บล็อกโทรช x2, หน้ากากเชื่อม
  - เหล็กแท่ง (Base.MetalBar) x2
  - ท่อโลหะ x2
  - ทักษะ Metal Welding 3+

ชุดท่อไอเสียปรับแต่งสมรรถนะ:
  - บล็อกโทรช x2, หน้ากากเชื่อม
  - ท่อโลหะ x2
  - น็อตสกรู (Base.Screws) x4
  - ทักษะ Mechanics 4+ และ Metal Welding 3+

(บูลบาร์ไม่ต้องคราฟต์ -- เป็นไอเทมของ tsarslib เอง หาได้จากจุดสปอว์นทั่วไปในโลกเกม)


ภาษาที่รองรับ
==============
อังกฤษ (EN) และไทย (TH) เต็มรูปแบบ -- ชื่อไอเทม, ชื่อสูตรคราฟต์, บทพูดตอนติดตั้ง/ถอดอุปกรณ์


รองรับ Multiplayer
===================
รองรับ -- ข้อมูล "ใครติดตั้งอุปกรณ์ชิ้นนี้ วันที่เท่าไหร่" จะ sync ให้ผู้เล่นทุกคนเห็นตรงกันผ่าน
ระบบ ModData มาตรฐานของเกม (part:getModData() + vehicle:transmitPartModData())


สถานะปัจจุบัน / ข้อจำกัดที่รู้อยู่แล้ว
======================================

- ม็อดนี้สร้างขึ้นหลังศึกษาม็อด "Standardized Vehicle Upgrades 3 - Core" ที่ใช้งานไม่ได้จริง
  (นิยามข้อมูลไว้เฉยๆ แต่ไม่เคยเรียกฟังก์ชันลงทะเบียนจริงกับรถคันไหนเลย) -- ม็อดนี้แก้ปัญหานั้นโดย
  เรียก tsarslib API (ATA2Tuning_AddNewCars) ลงทะเบียนกับรถกระบะจริงตั้งแต่แรก

- จุดที่ยังไม่ผ่านการทดสอบในเกมจริง: ฟังก์ชัน ATA2Tuning_AddNewCars ที่เป็นแกนของระบบทั้งหมด
  ไม่มีตัวอย่างการใช้งานจริงที่ทำงานสำเร็จอยู่ที่ไหนเลย (ไม่ใช่ใน tsarslib เอง ไม่ใช่ใน
  SVU3Core) -- เขียนตามการอ่าน validation logic ของ tsarslib อย่างละเอียดที่สุดแล้ว แต่ยังต้องเปิด
  เกมทดสอบจริงเพื่อยืนยันว่าอุปกรณ์ทั้ง 5 ชิ้นขึ้นในเมนู tuning ถูกต้อง

- รูปไอคอนของม็อด (icon.png/poster.png) เป็นภาพชั่วคราว ยังไม่ใช่งานศิลป์จริงของม็อด

- โมเดล 3D และเท็กซ์เจอร์ของไอเทมใหม่ 3 ชิ้น (แผ่นเกราะ, แร็ค, ท่อไอเสีย) ยืมมาจาก tsarslib
  (asset ทั่วไปที่ไม่ได้ผูกกับม็อดหรือรถคันไหนเป็นการเฉพาะ) ยังไม่ได้เช็คด้วยตาว่า UV/สัดส่วน
  แสดงผลถูกต้องสวยงามในเกมจริง

- รองรับแค่รถกระบะ (Pick-up Truck) คันเดียวในตอนนี้ การเพิ่มรถคันอื่นทำได้ง่ายในอนาคต
  (แค่เพิ่มรายการในตาราง NewCarTuningTable ของ HARMONIE_MA_TuningTable.lua)
