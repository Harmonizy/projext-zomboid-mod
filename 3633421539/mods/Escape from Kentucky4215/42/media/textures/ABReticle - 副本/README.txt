准心贴图目录（AB_Reticle 自动从这里加载，文件名固定，不可改名）

请把以下 7 张 PNG 放到本目录。全部使用透明背景；缺哪张，对应效果就不会显示（不会报错）。

  cat1.png   种类一：无瞄具（机械瞄具 / 普通准心）
  cat2.png   种类二：红点镜 / 全息
  cat3.png   种类三：中距离瞄具
  cat4.png   种类四：远距离现代瞄具
  cat5.png   种类五：二战瞄具
  dot.png    目标红点（压在僵尸身上时显示，会被程序着色成红色，白底小圆点即可）
  hit.png    命中倒三角（自带红色，尖角朝上；程序会旋转 4 次放在准心四周）

建议尺寸：
  cat1~cat5  128x128 或 256x256（程序以原尺寸显示，太大可用 PS 缩小）
  dot.png    64x64
  hit.png    64x64

说明：
- 准心为固定大小，射击时轻微放大再回落；命中僵尸时四周出现 4 个红三角。
- 若贴图放入后游戏里不显示，请确认 PNG 位于 media/textures/ABReticle/ 且文件名完全一致。
