==============================================================================
RULES ENGINE -- how a recipe's real stats/name decide which procedures it
needs (gen_craftdata.js addFinishingSteps() + applyAssemblyOverrides(),
the actual source of truth)
==============================================================================

A) Sharpness -- Swinging weapons only, and only if CriticalChance > 0
   (CritChance = 0 skips this category entirely). SINGLE-BAND-SELECT by
   CriticalChance (exactly one procedure, not cumulative):
     CritChance < 20        -> SharpenEdge
     20 <= CritChance < 40  -> StropLeather
     40 <= CritChance < 60  -> PrecisionGrind
     CritChance >= 60       -> ForgeShape

B) Piercing -- Spear/Stab weapons only, same CritChance > 0 gate and band
   shape as A:
     CritChance < 20        -> KnapHead
     20 <= CritChance < 40  -> TaperPoint
     40 <= CritChance < 60  -> PrecisionGrind (shared with A)
     CritChance >= 60       -> ForgeShape (shared with A)

C) Handle -- SINGLE-TIER-SELECT by MaxRange (the highest qualifying tier
   ONLY -- NOT cumulative; a handle can only be attached one way):
     MaxRange >= 1.6              -> MakeRivetedHandle, TightenBolts
     else MaxRange > 1.4          -> MakeLongHandle, ReinforcedBind
     else MaxRange > 1.2          -> MakeHandle, WrapBind

D) Balance -- CUMULATIVE by PushBackMod:
     PushBackMod >= 0.3  -> + HammerNails
     PushBackMod >= 0.5  -> + CounterweightHead
     PushBackMod >= 1.0  -> + WeldMetal

E) Structure -- CUMULATIVE by KnockdownMod:
     KnockdownMod >= 2  -> + RivetPlate
     KnockdownMod >= 3  -> + DrillCore

F) Toughness -- CUMULATIVE by ConditionMax:
     ConditionMax > 5   -> + WrapCloth
     ConditionMax > 10  -> + WrapLeather
     ConditionMax > 15  -> + StringSinew
     ConditionMax > 20  -> + WeaveWire

G) Wear Resistance -- CUMULATIVE by ConditionLowerChanceOneIn:
     ConditionLowerChanceOneIn > 10  -> + CoatMud
     ConditionLowerChanceOneIn > 20  -> + FireTreat
     ConditionLowerChanceOneIn > 30  -> + CoatWax
     ConditionLowerChanceOneIn > 40  -> + SurfaceCoating
     (real note: nothing in the current 248-recipe craftable pool
      actually exceeds 40, so SurfaceCoating is defined but currently
      never required by any real recipe.)

H) Assembly -- NAME-BASED, not stat-based. A real item whose OWN NAME
   describes a specific attached/constructed component gets that
   component's procedure INSTEAD OF whatever Sharpness/Piercing (A/B)
   would otherwise assign -- removes any of SharpenEdge/StropLeather/
   PrecisionGrind/ForgeShape/KnapHead/TaperPoint already picked, then adds
   the matching Assembly procedure. 4 specific named items get a fixed,
   EXCLUSIVE override -- their entire procedure list becomes just this one
   procedure, since the item itself already IS the raw material (a bottle
   you smash, a branch you snap, a plank you saw, glass/tools wrapped in
   cloth by hand, no tool needed) -- no other rule (C-G) applies on top:
     Handiknife/GlassShiv/Toothbrush_Shiv/HandFile -> WrapClothImprov (no tool)
     HalfPlank -> SawWood (tool only, no material consumed)
     SmashedBottle -> SmashBottle (tool = Base.HammerStone, a real stone)
     ShortTreeBranch -> BreakBranch (tool = SHARP_KNIFE)
   Everything else matches by real NAME SUFFIX and is ADDITIVE (only
   Sharpness/Piercing get swapped out, other categories still apply), e.g.
   any "*_Nails" item -> AssembleNails, any "*_Bone"/"BoneClub*" item ->
   AssembleBoneSpike, "*_BarbedWire"/"*BarbedWire" -> WrapBarbedWireAssembly,
   etc. -- see gen_craftdata.js's ASSEMBLY_PATTERNS for the full real-name
   lists). Real result: 75 of the 248 craftable recipes get an Assembly
   override; this also made ForgeShape currently unused alongside
   SurfaceCoating (the only 2 craftable items that ever qualified for
   ForgeShape, BucketMace_Metal/BucketMace_Wood, are also Assembly-matched).

A recipe's final procedure list is the UNION of every rule its own real
stats/name trigger across all 8 categories -- e.g. a long, heavy-swinging,
high-crit sword can require procedures from A, C, D, F, and G all at once.
Real range across all 248 recipes: 1 to 12 procedures per recipe.
