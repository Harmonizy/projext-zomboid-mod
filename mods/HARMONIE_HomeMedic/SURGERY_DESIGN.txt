ผลของการผ่าตัด = สถานะ treat (ของ EHR)
  treat = EHR_Medication.activeTreatments[โรค] -> โรคหยุดแย่ลง และหายเองเมื่อครบเวลา
  ผ่าสำเร็จ (>= 45%) -> treat ตามเวลาของโรค · ดีเยี่ยม (>= 80%) -> เวลาเหลือ 60%
  Wound Infection: หายทันที · กระสุน/เศษแก้ว: เอาออก · Knox: ตัดแขน (TOC) หรือยีนบำบัด
  โรคเดียวกันผ่าได้วันละครั้ง (ต่อคนไข้)

โรคที่ "ต้องผ่าตัด" ตั้งแต่ระยะ 3 (S.SURGICAL)
  Cellulitis, Sepsis, Tetanus, Trichinosis, Pneumonia, Cadaveric Aspergillosis, Toxin Poisoning,
  Hyperkeratotic Scabies, AHTR
  -> ถ้ากินยาครบคอร์สตอนอยู่ระยะ 3 ขึ้นไป: ยาไม่ทำให้หาย แต่โรคถูก "หยุดไว้" (รอผ่าตัด) นาฬิกาของโรคถูกแช่แข็งทุกนาทีเกม
     ระยะจึงไม่เพิ่ม -> ผ่าตัดแล้วได้ treat -> หาย
  -> ต่ำกว่าระยะ 3 หรือโรคอื่น: กินยาแล้วหายเหมือน EHR เดิม

UI
  - ทุกหน้าต่างวัดความสูงจากฟอนต์จริง, ตัดข้อความแบบไม่ตัดกลางตัวอักษรไทย, ขึ้นบรรทัดใหม่ในภาษาไทยที่ไม่มีเว้นวรรคได้
  - รายการที่ยาวเลื่อนด้วยล้อเมาส์ได้; tooltip คำนวณตำแหน่งจากเมาส์จริงแม้ตอนเลื่อน
  - แท็บ "วินิจฉัย": ทุกโรค/ภาวะ + ระยะ + สถานะ (กำลังรักษา / รอผ่าตัด / ต้องผ่าตัด) + ผลต่อร่างกายตอนนี้
  - คู่มือโรค: หัวข้อ "การผ่าตัด" บอกการผ่าตัดที่ใช้ได้ ระยะที่ต้องผ่า และเวลาหาย

MP
  ไม่มีอะไรทำงานทุก tick ยกเว้นการแช่แข็งโรคที่รอผ่าตัด (ทุก 1 นาทีเกม, เฉพาะผู้เล่นที่มีโรคถูกหยุดไว้)
